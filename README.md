# DFA-Minimization

## Sample Input

```
5
10
0 2 a
0 1 b
1 3 a
1 1 b
2 3 a
2 2 b
3 3 a
3 4 b
4 4 a
4 4 b
1
4
```

Format:
- `5` - number of states
- `10` - number of transitions
- each `x y a` - transition from state `x` to state `y` on symbol `a`
- `1` - number of accepting states
- `4` - the accepting state(s)
